# 聊天记录 → 报告 JSON 提炼指令

把这份文件连同导出的聊天记录一起交给 AI（WorkBuddy / Claude / 任意大模型），让它输出一份符合 `report/example.json` 结构的 JSON。

---

## 输入

1. `exports/<群名>_<开始日期>_<结束日期>.md`：导出的聊天记录，格式为
   `- **HH:MM 发言人**：内容`
2. 目标：生成一张"研究报告式"长图的内容数据

## 硬性规则

- **只用聊天里真实出现的内容**。数字、案例、原话、时间都必须能在记录里找到。
- **通读全部消息**，不要只看前 50 条。人数、条数、话题分布要基于全量统计。
- **不编造**。找不到的内容写"记录中未提及"，不要补。
- 引用必须**逐字或极接近原话**，并标注发言人和时间（HH:MM）。
- 群友发言选择**真实发言最多、观点最有代表性**的 6 人；姓名用群里的显示名。
- 如果内容涉及他人隐私（真实姓名、手机号、住址、身份证、未公开的商业信息），**自动替换为化名或删除**。
- 输出**纯 JSON**，不要 Markdown 代码块以外的解释。

## 内容要求

- `minis`：3-4 条，每条对应一个**真实现象**，不要写泛泛的方法论。
- `notes`：6-10 条，覆盖当天的主要话题，按"事实 → 细节"写。
- `people`：固定 6 人，`avatar` 留空（构建脚本会按名字自动匹配头像文件）。
- `quotes`：6 条，优先选**有情绪、有画面、能独立成句**的原话；`dark` 交替 true/false。
- `checklist`：5 条，必须是"明天就能做"的动作，不要写"提升认知"这种。
- `stats`：4 个数字，全部可在导出记录里核对。
